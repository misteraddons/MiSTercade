# MiSTercade 2P Encoder V2 Mappings (No Menu Combo)

2P Encoder V2 No-Menu mapping database for the [MiSTercade 2P Encoder V2](https://misteraddons.com/products/mistercade-2p-encoder-board).

This variant has the **menu combo (Down + Start) disabled** so it cannot be accidentally triggered during gameplay.

## How to Integrate into MiSTer Downloader

Add the following to the end of `downloader.ini` on your MiSTer SD card:

```ini
[misteraddons/mistercade_2p_encoder_v2_nomenu_mappings]
db_url = https://raw.githubusercontent.com/misteraddons/mistercade_2p_encoder_v2_nomenu_mappings/db/db.json.zip
```

Then run **downloader** or **update_all**.
